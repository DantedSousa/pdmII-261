# Avaliação 05 - Jogos de Linguagem (Ludwig Wittgenstein)

## 1. Conceito

Os Jogos de Linguagem foram desenvolvidos pelo filósofo Ludwig Wittgenstein. Segundo ele, o significado das palavras depende do contexto em que são utilizadas. Assim como em um jogo existem regras que determinam como os participantes devem agir, na linguagem existem regras que orientam o uso das palavras em diferentes situações.

Dessa forma, compreender uma linguagem significa compreender como ela é utilizada em um determinado contexto social.

## 2. Uso de Jogos de Linguagem no Ensino

Os Jogos de Linguagem podem ser utilizados no ensino para facilitar a aprendizagem por meio da prática e da interação entre os alunos. Em vez de apenas memorizar conceitos, os estudantes aprendem utilizando a linguagem em situações reais ou simuladas.

Entre os benefícios estão:

* Aprendizagem mais significativa;
* Maior participação dos alunos;
* Desenvolvimento do raciocínio crítico;
* Melhor compreensão de conceitos abstratos;
* Aprendizagem colaborativa.

Na área da programação, os Jogos de Linguagem ajudam os alunos a compreender conceitos por meio de exemplos práticos e situações do cotidiano.

## 3. Exemplo de Jogo de Linguagem em Programação Orientada a Objetos

Um exemplo é a simulação de uma empresa para ensinar Programação Orientada a Objetos.

### Classe

Pessoa

### Atributos

* nome
* idade
* cargo

### Métodos

* trabalhar()
* estudar()
* falar()

### Objeto

```dart
Pessoa funcionario = Pessoa("Carlos", 18, "Desenvolvedor");
```

Nesse contexto, os alunos aprendem os conceitos de classe, objeto, atributos e métodos utilizando situações próximas da realidade.

## Documentação do Jogo de Linguagem

### Nome

Construindo Objetos

### Objetivo

Compreender os conceitos fundamentais da Programação Orientada a Objetos.

### Materiais

* Cartões contendo classes;
* Cartões contendo atributos;
* Cartões contendo métodos.

### Desenvolvimento

1. O professor apresenta uma classe.
2. Os alunos recebem cartões com atributos e métodos.
3. Os alunos associam os cartões à classe correta.
4. Cada grupo cria objetos da classe.
5. Os resultados são discutidos em sala.

### Resultados Esperados

* Compreensão dos conceitos de POO;
* Identificação de atributos e métodos;
* Aplicação prática dos conceitos estudados.
