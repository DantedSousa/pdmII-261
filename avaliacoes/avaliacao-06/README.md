## Descrição

Esta atividade consistiu na execução do CodeLab **Flutter Animated Responsive Layout**, disponibilizado pelo Google Developers.

O objetivo do projeto foi desenvolver uma interface de e-mail responsiva utilizando Flutter, aplicando conceitos de:

* Layout responsivo;
* Material Design 3;
* Animações;
* Navegação adaptativa;
* Widgets personalizados;
* Organização de componentes.

## CodeLab Utilizado

https://codelabs.developers.google.com/codelabs/flutter-animated-responsive-layout?hl=pt-br

## Tecnologias Utilizadas

* Flutter
* Dart
* Android Studio
* Visual Studio Code

## Como Executar

1. Clonar o repositório.
2. Entrar na pasta do projeto:

```bash
cd animated_responsive_layout
```

3. Instalar as dependências:

```bash
flutter pub get
```

4. Executar o aplicativo:

```bash
flutter run
```

## Resultado

O aplicativo foi executado com sucesso em dispositivo móvel Android, apresentando a interface responsiva desenvolvida durante o CodeLab.

## Conclusão

A atividade permitiu praticar o desenvolvimento de interfaces modernas em Flutter, utilizando recursos de responsividade e animações para melhorar a experiência do usuário.
