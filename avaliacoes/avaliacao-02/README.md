### Atividade

Implementar uma Pilha.

1. Entender o funcionamento de uma Pilha;
2. Implementar o código para definir uma Pilha;
3. Implementar as funcionalidades:

* Mostrar o topo da Pilha;
* Empilhar;
* Desempilhar;
* Mostrar todos os elementos da Pilha;

4. Entregar o código e um print da execução.

## Objetivo

Compreender e implementar a estrutura de dados Pilha (Stack), utilizando os conceitos de inserção, remoção e visualização de elementos.

## Conceitos Utilizados

* Estruturas de Dados
* Pilha (Stack)
* LIFO (Last In, First Out)
* Programação em Dart
* Listas

## Funcionalidades Implementadas

* Empilhar elementos;
* Desempilhar elementos;
* Mostrar o topo da pilha;
* Exibir todos os elementos da pilha.

## Funcionamento

A pilha segue o princípio **LIFO (Last In, First Out)**, em que o último elemento inserido é o primeiro a ser removido.
