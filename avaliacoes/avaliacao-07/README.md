## Objetivo

Desenvolver o codelab proposto pelo Google Developers para criação e integração de widgets de tela inicial (Home Screen Widgets) em aplicações Flutter.

## Enunciado

* Executar o codelab disponibilizado pelo professor;
* Salvar o projeto no GitHub;
* Evidenciar a execução do aplicativo;
* Identificar o nome do aluno no título da aplicação;
* Adicionar um widget de tela inicial ao aplicativo Flutter.

## Tecnologias Utilizadas

* Flutter
* Dart
* Android Studio
* Visual Studio Code
* Home Widget Package
* Android Widgets

## Funcionalidades Implementadas

* Exibição de notícias na aplicação;
* Atualização de conteúdo através da interface Flutter;
* Integração entre Flutter e widget nativo Android;
* Atualização dinâmica do widget da tela inicial;
* Personalização do título da aplicação com a identificação do aluno.

## Como Executar

### Instalar dependências

```bash
flutter pub get
```

### Executar o aplicativo

```bash
flutter run
```

### Gerar widget da tela inicial

1. Executar o aplicativo no dispositivo Android;
2. Adicionar o widget à tela inicial;
3. Utilizar a opção "Update Homescreen";
4. Verificar a atualização do conteúdo diretamente no widget.
